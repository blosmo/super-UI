What your agent can do

  • Search components by task, name, library, or style.
  • Inspect a component with source excerpts, dependencies, license, and upstream references.

Hosted search uses semantic matching. Source excerpts may omit shared files and styles, so your agent should follow upstream setup instructions and test the result in your app. Preview links open on the web; this is not a visual app inside ChatGPT.
